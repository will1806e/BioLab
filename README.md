Trabalho para faculdade com o tema "Biomedicina: Sistema de Triagem e Alertas para Controle de Qualidade Laboratorial".

O sistema tem como objetivo gerenciar os equipamentos do Laboratório clinico de coleta de amostras, e gerar Gráficos de Levey-Jennings para observação dos dados e avaliar se o equipamento está dentro dos padrões normais e emitir alertas caso saia do padrão normal.
